# Andrey Popovich

## Projects

### [Blind Pew](https://github.com/gagafes/blind-pew)

Offline transliteration for Debian and Ubuntu, with GNOME and Xfce integration.
Choose from 9 input profiles for 8 languages on QWERTY or QWERTZ keyboards.
Press F12 or scroll over the tray icon to turn transliteration on or off.

[Download Blind Pew](https://github.com/gagafes/blind-pew/releases/latest) · [Documentation](https://github.com/gagafes/blind-pew#readme)

### [Malferma Libro](https://github.com/gagafes/malferma-libro)

A desktop ebook reader for Debian and Ubuntu, with a local library,
OPDS catalogs and a multilingual GTK interface.

[Download Malferma Libro](https://github.com/gagafes/malferma-libro/releases/latest) · [User guide](https://github.com/gagafes/malferma-libro/blob/main/docs/MANUAL.en.md)
